# Shell (now `@antfabric/ui-react/shell`, `@antfabric/ui-react-native/shell`)

- SidebarItem: `kind` removed → `glyph`, `icon`, `avatar`, `description`. `kind="channel"` → `glyph="#"`; `kind="private"` → `icon="lock" description="private channel"`; `kind="dm"` → `avatar`; `kind="group"` → `icon="users" description="group conversation"` (a group row on the phone is 44pt, as other icon rows).
- SidebarSection: `kind` → `icon` (`kind="starred"` → `icon="star"`); `onToggle` → `onCollapsedChange`; `items[i].onPress` → `onSelectedChange(name)`.
- WorkspaceSwitcher: every workspace takes `key`; `current` is a key (`current="Northwind Health"` → `current="northwind"`); the web add row reads `addLabel`.
- MobileHeader: `unread={n} onBell={f}` → `actions={[{ key: "notifications", icon: "bell", label: "Notifications", badge: n }]} onAction={f}`; `MobileHeaderAction` removed; `userName=""` draws no photo.
- TabBar: `onTab` → `onActiveChange`; `onExpand` → `onCollapsedChange`; `onFabric={f}` → `action={{ key: "assistant", icon: "sparkles", label: "Fabric" }} onAction={f}`; recipe parts `fabric`/`fabricIcon` → `action`/`actionIcon`.
- TitleBar: `onSidebarToggle` → `onSidebarExpandedChange`; `onMenu` → `onMenuOpenChange`; `onHelp={f}` → `actions={[{ key: "help", icon: "circle-help", label: "Help" }]} onAction={f}`; `history`, `search` are booleans.
- WebTopBar: `desktopApp` and `onOpenDesktop` removed: `desktopApp="open" onOpenDesktop={f} onHelp={g}` → `actions={[{ key: "desktop", icon: "square-arrow-out-up-right", label: "Open in desktop app", showLabel: true }, { key: "help", icon: "circle-help", label: "Help" }]} onAction={…}`; new `history`, `search`, `menu`, `trailing`.
- NavRail: `NavRailKey`, `NavRailDestination`, `NavRailSection` → core `NavItem`; `onNavigate` → `onActiveChange`; `onLevel` → `onLevelChange`; `onSection` → `onSectionChange`; `updateNotice` → `notice`; `notifications={n} onNotifications={f} onReport={g}` → `utilities={[{ key: "notifications", label: "Notifications", icon: "bell", badge: n }, …]} onUtility={…}`; new `logo`, `title`, `home`, `search`.
- AppMenuBar: `menus` is `{ key, label, items }[]` and `items` is removed: `menus={["App","File"]} items={view} openMenu="View"` → `menus={[{ key: "app", label: "App" }, { key: "view", label: "View", items: view }]} openMenu="view"`; items: `keys` → `shortcut`, `separator: true` → `type: "separator"`, `theme: true` → `type: "scheme"`, `trailing` → `trailingIcon`, `submenu: true` → `submenu: []`; new `workspaceIdentity`, `clock`.
