# Token glossary

Every word a token name is made of, once. Generated by `pnpm tokens:build` from `packages/core/src/naming.ts`: do not edit it. The same data is `/naming.json`; `pnpm describe tokens --find "<words>"` searches the tokens and `pnpm describe tokens --explain <path>` reads one name back.

## How a name is built

| Tier | Shape | Examples |
|---|---|---|
| Semantic | `category.property.role` | `color.text.muted`, `size.control.md`, `font.lineHeight.body` |
| Component | `componentId.partPropertyVariant` | `chip.removeSize`, `select.panelMaxHeight`, `chart.gridColor` |

The CSS variable is `--af-` plus the path in kebab case (`--af-color-text-muted`). In Figma the variable is the path with `/`. A mode (light, dark; web, desktop, mobile, Android) is never part of a name.

## Tiers

| Tier | What it is |
|---|---|
| `primitive` | A raw value mirrored from the product (`primitives.color.coral.500`). No component reads one. |
| `semantic` | A role any component may read, named category first (`color.text.muted`). |
| `component` | A value owned by the components its group names (`chip.removeSize`). An alias of a semantic token wherever the role is the same. |

## Categories and their properties

### `color`

A colour, by what it paints.

| Property | What it holds |
|---|---|
| `color.text` | Text and icons. |
| `color.background` | Fills and surfaces. |
| `color.border` | Edges, dividers and focus rings. |

### `font`

Type.

| Property | What it holds |
|---|---|
| `font.family` | A font family. |
| `font.size` | A font size. |
| `font.lineHeight` | The line height that goes with the size of the same name. |
| `font.weight` | A font weight. |
| `font.letterSpacing` | Letter spacing, in em. |
| `font.file` | The file the phone loads for a face and a weight. |

### `size`

The size of a thing: a height, a width or a side.

| Property | What it holds |
|---|---|
| `size.control` | A control's height. |
| `size.icon` | An icon's side. |
| `size.stroke` | An icon's line weight. |
| `size.dot` | A status dot's diameter. |
| `size.row` | A list row's height. |
| `size.avatar` | An avatar's side. |
| `size.target` | The least a pointer or touch target is. |
| `size.layout` | The app frame: rails, bars and insets. |

### `space`

Padding, gaps and margins: one scale, and the gutters under `space.gutter`.

### `radius`

A corner radius, named for the thing that wears it.

### `border`

A border's width. Its colour is `color.border.*`.

| Property | What it holds |
|---|---|
| `border.width` | A border's width. |

### `motion`

How things move.

| Property | What it holds |
|---|---|
| `motion.duration` | How long. |
| `motion.easing` | The curve. |

### `elevation`

Lift off the surface.

| Property | What it holds |
|---|---|
| `elevation.shadow` | A shadow. |

### `zIndex`

Stacking order.

### `opacity`

A fade applied to a whole element.

### `effect`

A material's filter values.

| Property | What it holds |
|---|---|
| `effect.glass` | Liquid Glass: blur and saturation. |

## What a component token's key ends in

| Word | The value is |
|---|---|
| `Height` | A height. |
| `Width` | A width. |
| `MinHeight` | The least height. |
| `MaxHeight` | The most height. |
| `MinWidth` | The least width. |
| `MaxWidth` | The most width. |
| `Size` | A side or a diameter, where width and height are one. |
| `Radius` | A corner radius. |
| `Gap` | The space between two things. |
| `Padding` | Padding on every side. |
| `PaddingX` | Padding at both sides. |
| `PaddingY` | Padding above and below. |
| `PaddingLeft` | Padding at the start. |
| `PaddingTop` | Padding above. |
| `Inset` | How far in from an edge. |
| `OffsetX` | A sideways shift (negative hangs outside). |
| `OffsetY` | A vertical shift (negative hangs outside). |
| `Offset` | A shift on both axes. |
| `Overhang` | How far past an edge. |
| `FontSize` | A font size. |
| `LineHeight` | A line height. |
| `Color` | A colour. |
| `Shadow` | A shadow. |
| `FontFamily` | A font family. |
| `FontFile` | The phone's font file. |
| `Dash` | The length of a dash. |
| `Travel` | How far a part slides. |
| `Breakpoint` | The width at which the layout changes. |

## Sizes, states and emphasis

Sizes: `xxs`, `xs`, `sm`, `md`, `lg`, `xl`, `2xs`, `3xs`, `2xl`, `3xl`, `4xl`, `5xl`.

| State | When |
|---|---|
| `hover` | Under the pointer. |
| `pressed` | Held down. |
| `focus` | Has keyboard focus. |
| `selected` | The current or chosen one. |
| `disabled` | Cannot be used. |

| Emphasis | Meaning |
|---|---|
| `subtle` | Quietest. |
| `muted` | Quiet. |
| `default` | The usual one: no word is also the default. |
| `strong` | Loudest. |

## Other words for the same thing

| Here | Elsewhere |
|---|---|
| `color.background` | Called surface in some systems: a fill something sits on. |
| `color.text` | Called foreground (fg): text and icons. |
| `soft` | A pale wash of a colour, for a tinted surface. Text on it is `on<Colour>Soft`. |
| `on<Fill>` | The text and icon colour that reads on that fill: `color.text.onBrand` on `color.background.brand.default`. |
| `lineHeight` | Called leading. |
| `letterSpacing` | Called tracking. |
| `scrim` | The dim layer behind a modal: a backdrop. |
| `target` | The area a pointer or a finger can hit, which may be larger than what is drawn. |
| `gutter` | The space between panes and around a page. |

## Component families

|---|---|
| `chart` | bar-chart, breakdown, combo-chart, donut-chart, gauge-chart, goal-rings, line-chart, meter, metric-tabs, period-compare, progress-ring, radar-chart, spark-bars, sparkline |
| `sheet` | bottom-sheet, context-menu, dialog, in-app-banner, notification-schedule, permission-prompt, select, sheet, tab-bar, update-banner, workspace-switcher |
| `choice` | checkbox, radio-group, select, switch |
| `checkbox` | checkbox, composer, list-item, menu |
| `textField` | form-field, text-area, text-field |
| `menu` | context-menu, menu |
| `kpi` | kpi-card, meter, metric-tabs, period-compare, progress-ring, spark-bars, stat-tile |
| `navRail` | nav-rail, workspace-switcher |
| `sidebarSection` | sidebar-item, sidebar-section |
